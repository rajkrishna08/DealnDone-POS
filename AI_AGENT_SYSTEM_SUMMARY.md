## 🚀 **How to Use the AI Agent**

### **Command Line Interface**
```bash
# Run full diagnosis and fix
python run_ai_agent.py

# Run diagnosis only
python run_ai_agent.py diagnose

# Run automatic fixes
python run_ai_agent.py fix

# Start continuous monitoring
python run_ai_agent.py monitor

# Show help
python run_ai_agent.py help
```

### **API Endpoints** (when integrated with backend)
- `GET /ai/health` - Quick system health check
- `POST /ai/fix` - Run automatic fixes
- `GET /ai/diagnosis` - Comprehensive system diagnosis
- `GET /ai/recommendations` - AI recommendations
- `GET /ai/status` - Agent status

### **Web Dashboard**
Open `ai_dashboard.html` in your browser for a visual interface.
